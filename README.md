## 🚀 Featured Project

### ⌨️ TypeFlow — Full-Stack Typing Practice Platform

A full-stack typing practice application designed to help users improve their **typing accuracy and speed** through interactive typing tests.

**Key Features:**

* 🔐 User registration & login
* 📧 Email verification with 6-digit OTP
* ⏱️ OTP expiration after 10 minutes
* ⌨️ Character-by-character typing validation
* 📊 Accuracy & WPM tracking
* 🔄 Two-round performance comparison
* 💾 Persistent typing history
* 🎹 Interactive on-screen keyboard
* 📈 Typing progress tracking
* 🌐 Cloud deployment

**Tech Stack:**

`Python` `Flask` `JavaScript` `HTML` `CSS` `MySQL` `Resend` `Gunicorn` `Render` `Aiven` `GitHub`
